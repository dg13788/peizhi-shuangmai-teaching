# 开源上架发布检查清单（Release Checklist）

> 本文件为 **GitHub 开源上架的唯一逐项检查清单**（依据 SKILL.md §15 开源上架指引维护）。
> 每次发布（含主版本与修订版本）前逐项打钩执行；任一 ☐ 未通过不得上架。
> 完成后将"发布执行记录"追加至本文件末尾（版本 / 日期 / 执行人 / 逐项结果）。

## 一、仓库结构与文件完整性

- [ ] 仓库根目录存在 `SKILL.md`（引擎主体，front-matter 完整：name / display_name / version / author / description / tags / compatibility / license / requires）
- [ ] 以下开源配套文件齐全且内容与当前版本一致：
  - [ ] `README.md`（项目简介 / 特性 / 快速开始 / 安装 / 仓库结构 / 隐私说明 / 致谢 / 许可证 / 版本与兼容性）
  - [ ] `LICENSE`（MIT 主许可 ＋ 附加条款：红区护栏不可移除 / 署名保留 / 商业用途限制 / 隐私责任边界 / 方法论文献声明）
  - [ ] `CHANGELOG.md`（日期 / 版本号 / 变更类型 / 变更说明；与 SKILL.md §10、§16 版本历史同步）
  - [ ] `examples/`（至少 1 篇实跑教案；`培智二年级生活数学_5的认识_v1.0.md` 为验收基准）
  - [ ] `CONTRIBUTING.md`（贡献边界 / 流程 / 回归测试最小集 / 红区红线 / ISSUE 模板）
  - [ ] `docs/release-checklist.md`（本文件）
  - [ ] `.gitignore`（默认排除 Word/PDF 成品与工作中间产物）

## 二、README 要求

- [ ] README 含"红区零输入"隐私与安全说明，位置醒目
- [ ] README 含外部方法论致谢清单（§3.2）
- [ ] README 标注版本号与兼容性（1.x 主线、迁移说明）
- [ ] README 的安装方式覆盖"SKILL 目录 / 无 SKILL 平台提示词复制"两类环境

## 三、LICENSE 附加条款

- [ ] LICENSE 含"禁止移除或弱化红区零输入护栏"条款（最高优先，任何衍生版本必须保留）
- [ ] LICENSE 含"衍生作品保留署名（Xd_香墩）与原始版权声明"条款
- [ ] LICENSE 含"商业培训 / 付费课程 / 商业化产品须事先取得书面授权，或文档/模板部分采用 CC BY-NC-SA 替代"条款
- [ ] LICENSE 含隐私责任边界与疗效免责声明

## 四、全库隐私扫描（红区零输入）

- [ ] 全库无真实学生姓名（仅允许代号"生1/生2…"或占位符 `{{字段名}}`）
- [ ] 全库无学生照片 / 人脸图片 / 含学生影像的媒体文件
- [ ] 全库无病历 / 身份证号 / 手机号 / 长数字串（已用正则扫描：身份证 17+ 位、手机号 11 位、任意 ≥11 位连续数字）
- [ ] 全库无家庭敏感结构等真实个人身份信息
- [ ] 扫描记录留存（工具输出 / 本文件"发布执行记录"注明扫描方式与结论）

## 五、git 与提交历史

- [ ] `git status` 复核实跑产物（锚定单 / 内容提取卡 / Word / PDF）**未入暂存区**（受 .gitignore 排除；确需归档的用 `git add -f` 并人工确认无红区）
- [ ] 提交历史即权属时间戳：首提交含 LICENSE 与版权声明，作者署名一致（Xd_香墩）
- [ ] 提交信息规范：标注版本号（如 `release: v1.0`），与 CHANGELOG 对应
- [ ] 无真实学生信息进入过任何提交历史（若历史含红区，须重写历史或移除外链）

## 六、白名单与版本升版防复发

- [ ] 全库隐私扫描白名单（允许出现的红区词仅限护栏规则声明文本，如"不得输入学生姓名/病历"）随版本升版复核，防复发
- [ ] 新增/修改环节破坏示例教案时，已升大版本并更新 examples 与 CHANGELOG（§9）

## 七、合规确认

- [ ] 职务作品书面确认：作者确认本作品非职务作品 / 已获单位授权（按实际情况勾选并留存书面确认）
- [ ] 商业用途授权边界已写入 LICENSE，作者联系方式（如需商务授权）已在 README 或 ISSUE 模板可寻址处给出

## 八、回归测试最小集（§9，发布前必跑）

- [ ] 示例课题实跑 1 篇，产出一致（环节数、五列表〔含 BOPPPS 步别、≥1 个探究活动、时间合计=课堂时长〕、目标矩阵、LOS 表齐全）
- [ ] 附件识别回归：内容提取卡七字段齐全（含红区拦截记录）、回填环节 0/1 生效、红区拦截生效
- [ ] Word+PDF 双格式生成成功，§13.1 格式基线核验全过
- [ ] 全库扫描无真实姓名/照片/病历（红区零输入）
