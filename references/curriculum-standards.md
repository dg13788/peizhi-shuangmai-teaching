# 课标依据权威索引（培智学校·2016年版）

> **何时读**：进入「课标锚点」环节前**必读**；教师所报学科名不在本文清单一览表内时**必读**；
> 写「教案信息 · 课标锚点」行（3.17.0 起唯一正式信息源，须写三级全文）前**必读**。
> **地位**：本文件是课标引用的**唯一口径源**。书名、一级领域、学段命名一律以本文为准，
> **禁凭记忆或印象补全**，禁跨体系拼凑。

## 一、唯一合法课标与出处

- **法定依据**：教育部《关于发布实施盲校、聋校、培智学校义务教育课程标准（2016年版）的通知》
  （**教基二〔2016〕5 号**），2016-11-25 发布，**2017 年秋季学期起执行，现行有效**。
- **培智学校唯一的国家课标**：《培智学校义务教育课程标准（2016年版）》，共 **10 门**。
- **检索与核对**：教育部政府门户网站 `http://www.moe.gov.cn/` 检索「教基二〔2016〕5 号」；
  已核到全文的公开 PDF 见 `https://www.ictr.edu.cn/Uploads/File/2022/05/23/`（各门课一个文件）。
  第三级"具体表述"**必须逐字回到原文核对**。
- **禁引清单**（命中即为错引，回归自动拦截）：
  ① 《义务教育…课程标准（**2022年版**）》系列 —— 这是**普通学校**课标，**不可套用于培智学校**；
  ② 《**聋校**义务教育…课程标准》；③ 《**盲校**义务教育…课程标准》；
  ④ 任何其他版本、任何年份、任何地方自行制定的"课标"冒称国家课标。
- **科目不在 10 门内**（如英语、物理、化学）：**显式告知**"该科目不在培智学校义务教育课程标准体系内"，
  并入 **Gate-A 口径确认**；确认后按无国家课标处理，标注「无对应国家课标，目标依据为校本课程／IEP」，
  **禁编造课标书名**。

> 信息技术与康复训练按水平且康复训练**不分学段**。此前曾怀疑样例中"低年级段"与"第一学段"
> 并存是口径不一致，逐条核到原文后**证伪——两者都对**。

## 三、学科别名映射（命中即须对齐，并留对齐凭证）

| 教师常说 | 培智课标口径（正式科目） |
| --- | --- |
| 美术／画画／美工／绘画／手工／涂色 | 绘画与手工 |
| 音乐／唱歌／唱歌游戏 | 唱游与律动 |
| 体育／运动／保健／体操 | 运动与保健 |
| 语文／识字／阅读／说话 | 生活语文 |
| 数学／算术／数数 | 生活数学 |
| 劳动／家政／烹饪／打扫 | 劳动技能 |
| 计算机／电脑／信息／网络 | 信息技术 |
| 感统／言语／康复／作业治疗／物理治疗 | 康复训练 |
| 休闲／课外活动／兴趣活动 | 艺术休闲 |
| 品德／社会／常识／适应／生活能力 | 生活适应 |

**为什么必须有这张表**：培智体系中**没有"美术"这门课**——培智对应的是「绘画与手工」，
而**普校有美术/艺术、聋校有美术、盲校有美工**。三者并存时，若不给显式映射，
模型会滑向普校或聋校课标拼凑，产出看似专业实则错引的教案。这是已发生的真实缺陷。

**对齐凭证（强制）**：命中别名时，成品「教案信息·学科」与「课标锚点」处须写明
`教师输入「{{原词}}」→ 按培智课标口径对齐为「{{正式科目}}」`。
**禁直接改写而不留痕**——不留痕会让教师误以为自己的提法就是正式科目名。

## 四、待确证项（禁凭印象补全）

- **艺术休闲**：一级领域（休闲认知／休闲选择／休闲技能／休闲伦理）与学段命名均来自二手转述，
  未取得教育部原文逐字确证。使用时**须标注"待核对"**，交付前由教师以课标原文核对；
  **不得据本文直接用于正式归档**。
- **各门课的具体条目原文**（锚点第三级）：本文只给到一级领域。条目名与原文表述**必须**回到
  教育部 PDF 逐字核对；不确证一律标"待核对"，**禁凭印象补全**。
- 已逐字确证的可引用条目（样例中使用过，可直接复用）：
  - 生活语文·低年级段：「认读生活中常用汉字10～50个」「能用铅笔描写或抄写生活中常用汉字」
    「能用普通话朗读简单句」「会诵读诗歌（儿歌、古诗）5～10首」「能结合图片的内容，理解词、句的意思」（选学）
  - 生活数学·第一学段·数与运算·数的认识：「在现实情境中，理解10以内数的含义，能数、认、读、写，
    强调手口一致地点数10以内的物体」「通过动手操作，了解10以内数的组成，会比较它们的大小」
  - 生活数学·第一学段·常见的量：「感知物体的有无、多少、同样多，会区分」
  - 绘画与手工·第一学段·造型·表现：「尝试用点、线、图形和色彩进行涂画活动，初步学会涂色」
    「认识常见物品的颜色」「根据身边物品的颜色进行简单的配对分类」
  - 绘画与手工·第一学段·设计·应用：「观察、触摸身边常见的简单物品，初步了解其形状、颜色、大小与用途」
  - 绘画与手工·第一学段·欣赏·评述：「能在欣赏活动中注视、追视目标」「乐于参与欣赏学习活动，保持相对稳定的情绪」
  - 绘画与手工·第一学段·综合·探索：「了解绘画与手工的不同表现形式」「乐于参与绘画与手工活动，表达自己的感受」

> ⚠ 课标**解读类文献**（专家解读、地方标准转述）中的表述**不是课标原文**，
> 例如"按物点数、说出总数、按数取物、掌握计数原则"出自课标解读而非课标条文，
> **不得当作课标原文引用**。

## 五、引用格式（锚点三级）

```
一级领域 ｜ 学段 · 二级条目 · “课标原文表述”
```

- **第一级必须落在该科"一级领域"枚举内**。「课程总目标」「学段目标」「教学建议」「评价建议」
  是课标的**篇章名**而非内容领域，**不得充当锚点第一级**——它们不能作为教学目标依据，
  用作一级会让锚点退化成无法核对的泛泛而谈。
- 三级缺一不可；原文表述加中文弯引号；**非原文的转述须显式标"转述"**，未确证标"待核对"。
- 三视图（教师一页速览／教师全量／家校反馈）＋「教案信息」节**全部保留三级**，禁只写学段（三视图的定义见 `references/workflow.md`「环节 3 · 研判精修 + 三视图」）。
- 教学建议类内容如需保留，另起一行标注「（课标实施建议，非锚点，仅供实施参考）」，
  **不得混入锚点条目**。

## 六、示范：教师说「美术」时怎么落（正确 vs 错误）

**输入**：课题《给苹果穿红衣裳》，教师口语学科"美术"，二年级，共 2 课时。

**第一步 · 别名对齐（必须留痕）**

> 教师输入「美术」→ 按培智课标口径对齐为「绘画与手工」。

（培智学校义务教育课程体系内**没有"美术"**；普校有美术/艺术、聋校有美术、盲校有美工，
三者**都不是**培智课标，禁引用。）

**第二步 · 教案信息写法**

| 项目 | 内容 |
| --- | --- |
| 学科 | 绘画与手工（教师输入「美术」→ 按培智课标口径对齐为「绘画与手工」） |
| 课标锚点 | 《培智学校义务教育绘画与手工课程标准（2016年版）》· 造型·表现 · 第一学段（1~3年级）· 涂画活动 · “尝试用点、线、图形和色彩进行涂画活动，初步学会涂色”；· 设计·应用 · 第一学段 · 观察与模仿制作 · “观察、触摸身边常见的简单物品，初步了解其形状、颜色、大小与用途”；· 欣赏·评述 · 第一学段 · 参与欣赏 · “能在欣赏活动中注视、追视目标” |

> ⚠ 上表是本索引**自己的示范**，同样受第五节约束：锚点必须写三级全文、禁只写学段、禁以
> “（详见……节）”代替本行，命中别名必须留对齐凭证。**示范件违反自己声明的规则，比没有示范更坏**
> ——引擎与教师都会照抄示范，3.20.0 前此处正是“只写学段＋详见……节”的退化写法，
> 而回归只扫 `examples/`，示范表长期在校验盲区里。

**第三步 · 锚点三级**

- 造型·表现 ｜ 第一学段（1~3年级）· 涂画活动 · “尝试用点、线、图形和色彩进行涂画活动，初步学会涂色”
- 造型·表现 ｜ 第一学段 · 认识与配对颜色 · “认识常见物品的颜色”“根据身边物品的颜色进行简单的配对分类”
- 设计·应用 ｜ 第一学段 · 观察与模仿制作 · “观察、触摸身边常见的简单物品，初步了解其形状、颜色、大小与用途”
- 欣赏·评述 ｜ 第一学段 · 参与欣赏 · “能在欣赏活动中注视、追视目标”“乐于参与欣赏学习活动，保持相对稳定的情绪”

**常见错误（命中即判错引，回归自动拦截）**

| 错误写法 | 为什么错 |
| --- | --- |
| 《义务教育艺术课程标准（2022年版）》 | 普通学校课标，不适用于培智学校 |
| 《聋校义务教育美术课程标准》 | 聋校体系；且"美术"在培智课标中不存在 |
| 《盲校义务教育美工课程标准》 | 盲校体系 |
| 锚点第一级写「课程总目标」「教学建议」 | 是课标篇章名、不是内容领域，不能作教学目标依据 |
| 只写"第一学段"不写领域与条目 | 锚点未达三级 |

## 七、用户上传课标文件时

用户上传课标 PDF／图片／文本时，**以用户文件为准**（先检测后识别，命中红区即停），
并在成品标注「课标依据来源：用户上传文件（{{文件名}}）」；与本文冲突时以用户文件为准，
并留一行差异说明。**用户文件优先于本索引**——本索引是兜底口径，不是上限。
