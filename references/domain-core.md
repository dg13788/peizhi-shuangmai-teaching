# 领域内核（SKILL.md §0 完整展开）

> **渐进式披露第二层**。SKILL.md 常驻"五条铁律名称 + 定位 + 关键枚举"，本文件承载**判定口径细节**。
> 触发读取时机：判定红区、处理行为事件、定支持强度、做感官前置安排、写晋级降级决议、写 Gate 话术。
> 本文件与 SKILL.md 同属引擎契约：改任一处须同步另一处并跑 `python scripts/regression_check.py`。

## 1. 五条铁律（判定口径，任何环节不可违背）

1. **红区零输入零输出**：学生姓名、身份证、病历、人脸照片、家庭敏感结构，一律零输入零输出（含附件与 Word 成品），学生一律代号"生1/生2…"；附件识别前先做红区检测，命中即不识别、不输出、提示脱敏后重传。护栏不因低打扰协议或任何理由豁免。
2. **学情禁编造**：学情线索不具备时停等补齐（Gate-B），不得用"默认＋假设清单"豁免、不得静默编造；其余基线缺失可默认＋假设并在锚定单集中列出待替换项。允许沿用历史锚定单/上一课学情，但须标注来源并注明"课前现场核对"。
3. **教材禁杜撰**：教材内容匹配以公开教材目录/教参/课标为据，输出到"教材版本 → 册次 → 单元 → 课"粒度；检索不确证时标"未确证"入待替换项，禁止幻觉书名/出版社/页码。
4. **课标锚点三级**：标注到"板块 · 条目 · 具体表述"（如"第一学段 · 数的认识 · 能点数 5 以内物品的数量"），禁只写学段；**四个视图全部保留锚点三级**（含教务归档版）。
5. **时长恒等**：默认 35 分钟 1 课时（用户显式指定则从之）；**每一课时的五列表分钟数之和恒等于该课时时长**（多课时逐课时独立校验，不得跨课时相加），分钟数一律整数。

## 2. 课时量研判（1~N 课时，引擎主动研判，非默认/非必问）

**研判身份**：`{{学科}}资深教学专家 ＋ 培智学校特级教师`（**双身份，缺一不可**——前者保证学科内容量算得准，后者保证培智课堂的真实耗时被算进去）。

**研判时点**：环节 0 第 3 步（7 项基线）之后、**Gate-A 之前**（此时课标锚点三级、教材定位、内容理解、学情分层均已具备，依据才站得住）。

**测算式**：`N = ceil(基础时长 × 复现系数 × 分层系数 ÷ 有效利用时长)`

- **基础时长** = Σ（本课知识点/技能点 × 单点基准时长）。**培智课堂单点 6~10′**（含"教师演示 → 学生模仿 → 逐一反馈"；普教 2~3′ 口径不可套用）。知识点按"感知 → 理解 → 表达/应用"三阶拆分计数，同阶多例不重复计。
- **复现系数 1.2~1.5**：培智生需过量学习，同一目标 ≥3 轮不同形式复现（实物 → 图卡 → 情境）；C 层占比高或障碍程度重取上限。
- **分层系数 1.1~1.3**：按 A/B/C 人数占比加权；C 层需全辅助＋多感官重复演示，**C 层占比 ≥1/3 取上限**。
- **有效利用时长** = 单课时时长 × **0.75**（35′→26′、25′→18′、40′→30′）：其余被导入、组织过渡、个别支持、行为处理、总结占掉。**普教"整课时可用"口径在培智课堂必然失效，此为硬扣除**。
- 结果向上取整；**N>3 须特别论证并一律转"输出确认"**。

**学科校验锚（典型区间，用于防算出离谱值）**：

| 学科 | 常见课时 | 口径说明 |
|---|---|---|
| 生活语文 | 2~3 | 识字/阅读/表达需多轮复现与句式迁移 |
| 生活数学 | 2~3 | 概念建立 → 操作练习 → 生活应用三段 |
| 生活适应 | 2~3 | 情境模拟＋实景迁移各占一段 |
| 劳动技能 | 2~3 | 技能链分解＋实操熟练 |
| 绘画与手工 | 1~2 | 以单件作品完成度为一段 |
| 唱游与律动 | 1~2 | 活动闭环自成一段 |
| 运动与保健 | 1~2 | 单技能＋体能，准备/放松必占时 |
| 康复训练 | 1 | 按个别化计划执行，不按班级课时切分 |
| 其他/校本 | 2 | 默认，须论证 |

**收敛规则**：测算值落在学科区间内 → 采纳；落在区间外 → 以区间为校准重取，**差异 ≥1 课时者转"输出确认"**并在待替换项注明差异。

**双出口判定（研判之后如何确定）**：

| 出口 | 触发条件（**须全部满足**） | 表现 |
|---|---|---|
| **轻打扰直定**（不停等） | ①测算值落在唯一区间且**边界余量 >10%**（无"可 1 可 2"式摇摆）②N ≤ 3 ③用户未指定，或指定值与研判一致 ④教材/课标无硬性课时规定冲突 ⑤学科校验锚一致 | 一句话带过结论（含依据＋"如需改为 X 课时请说"），**直接续进环节 1** |
| **输出确认**（并入 Gate-A 停等） | 任一不满足：**边界摇摆**（余量 ≤10%）/ N>3 / 用户指定值与研判冲突 / 教材单元或校历规定课时 / IEP 周期约束 / 附件信息不足以测算 | 结论随 Gate-A 一并展示，确认后进入环节 1 |

**边界余量** = （ceil 值 − 测算值）÷ ceil 值。例：测算 1.66 → ceil 2，余量 17%（直定）；测算 2.88 → ceil 3，余量 4%（摇摆 → 确认）。

**出口凭证（硬要求，3.14.0 立）**——**判定不许只在研判表里落一笔就了事，出口必须有凭证**：

| 出口 | 交付稿中的凭证 |
|---|---|
| **轻打扰直定** | 研判表「确定方式」须写明不停等依据（**余量实测值**＋N ≤ 3），一行即可 |
| **输出确认** | 须另起 **Gate-A 确认记录块**：`确认事项`／`备选项（如 2 课时／3 课时）`／`教师确认结果（占位 {{}}）`／`确认后结论`，并与「待替换项与假设清单」相互指引 |

**无凭证即视同 Gate 未走完**。3.14.0 起因：一份基准样例在研判表判定"输出确认（随 Gate-A 一并确认）"，而成品里 **Gate-A 零落点**——教师读到的是一条"宣称要停等、实际径直跑完全部课时"的路径，示范件自己违反了自己宣称的规则。反过来，「轻打扰直定」的样例**不得**出现 Gate-A 块，否则双出口边界在示范中失焦。

**用户已指定课时数时**：仍出研判结论作校验——**一致 → 一句带过**；**冲突 → 标出差异但采纳用户值，不停等**（用户主权优先，专业提示留痕）。指定值写入锚定单，并在待替换项注明"用户指定，与研判差 X 课时"。

**切分依据（硬口径）**：**以目标三阶切课时，不以"内容讲不完"切课时**——同一目标格不跨课时重复计，按"感知 → 理解 → 表达/应用"递进切分。

**每课时自成闭环**（与课时数无关，恒执行）：独立目标矩阵分表、独立五列表（含 BOPPPS 六步与 ≥1 探究活动）、独立前测/后测、独立分层作业、独立板书。
- **跨课时**：先出"课时总体安排表"（课时 / 主题 / 核心目标 / 生活化落点）；上一课时后测达成＝下一课时起点；生活泛化首尾呼应；LOS 记录表逐课时成对记录（见环节 4）。
- **课时间目标不重复**：同一目标格不跨课时重复计，按"感知→理解→表达/应用"递进切分。

## 3. LOS 六级（唯一枚举）

**支持强度递增** 独立(I) → 口头(V) → 手势(G) → 身体(P) → 完全辅助(F)。**无参与(N)** 不属支持强度序列，表示未进入参与——触发优先参与目标＋环境与任务调整，不计入该生本课学业达成判据。A/B/C 为分层单位，个体档差可在 LOS 表内标注（如 A-、C-，注明对应 LOS 档），不改变三层结构。

**课堂分组落法**：A 独立·口令提示·步骤卡；B 半独立·关键词提示·图卡·少量肢体辅助；C 辅助·手势示范·实物示范·全辅助或 AAC。

## 4. 感官调节前置（前因层，先于任务与强化调整）

行为干预的第一步不是要求，而是**先把环境刺激降到学生能学的水平**——**六维度**须前置评估并写入配套件《感官调节与环境安排表》（`维度 / 触发信号 / 前置安排 / 课中降刺激通道`），列入课前核对单：

1. **听觉**（噪声、音量固定档、搬动物声）
2. **视觉**（光线、闪烁、投屏白底黑字禁动画）
3. **前庭与座位**（固定座位表、站位与扶杆、易离座生靠内侧）
4. **口欲与过敏**（细物换大号教具、过敏确认、替代咀嚼物、禁强制进食；**含品尝课时另加味觉与质地防御**，见下）
5. **触觉与材料**（一式两份、按序发放、替代材质）
6. **嗅觉**（气味源位置与通风、闻味一律自愿、香味物品禁作奖励发放）

**品尝类环节的味觉前置（3.13.0 立）**——第 6 维之外没有独立的"味觉"维度，**含进食/品尝的课程把该项并入第 4 条「口欲与过敏」行写明**，不得只写"切小块、专人看护"就了事。须补三条：**质地**（每生可接受的食物软硬度清单，由助教记入感官备注）、**吐出**（吐出一律记为"尝试"，不追加强化要求，**禁说"再吃一口"**）、**自愿**（禁强制进食已在口欲行，此行须写"允许吐出不批评"）。理由：挑食、拒生鲜、只接受单一质地是培智生最常见的味觉防御表现，而 PBS 卡里往往已经记"品尝环节的吐出与拒食"为触发信号——**前置安排里没有对应项，就等于信号与应对脱节**，教师临堂只剩"再试一口"。

**感官配具须同步进材料清单**（3.13.0 立）——本表写"配牙胶""配替代咀嚼物"而材料清单无此条目，等于课前照单核对时必然漏带；参照材料闭环：感官节提到的配具，材料清单必须列。

**与上表配套的感官前置对齐规则（3.7.0 立）**——**教学过程用到哪个感官通道，本表就必须有该维度行**：例如教学过程出现"闻"（闻水果香味、闻气味辨物）而本表无嗅觉行，等于气味过敏与掩鼻回避毫无前置安排，是本类课堂最常见的安全缺口。反之，未用到的维度不必硬凑。

降刺激通道必须是**立即可执行且不具惩罚性**（如静音手势卡、纸质大图卡替代投影、允许站立、换通道轮换），**禁以冷静角/隔离作为唯一通道**。

## 5. 跨课时行为干预递进（PBS，多课时必备；单课时执行简化版）

- **ABC 简录**：行为事件一律三格记录——前因(A，发生了什么) → 行为(B，可观察可计数，**禁写"情绪失控/不配合/故意"等评价词**) → 后果(C，教师如何处置)；落 LOS 表备注或行为记录行。
- **替代行为须先教**：布置的替代行为（举手 / 插卡 / 出示暂停图卡）必须在先前课时已教学并练习 ≥2 次，禁要求未教过的替代行为；且与目标行为功能对等（DRA/DRI）。
- **强化削弱计划**：课时1 连续强化（每次正确即强化）→ 课时2 固定比率（FR2/FR3）→ 课时3 变动强化＋社会性强化为主、物质强化淡出；强化物设轮换清单防饱和（**N>3 时按三段循环：中段维持 FR3/VR2，末段淡出**）。
- **晋级/降级阈值（写入配套件，跨会话一致）**：
  1. 达成率 ≥80% 且独立尝试成功率 ≥80% **连续 2 课时** → 下一课时降一级支持（F→P→G→V→I），降级后须观察 1 课时，回落则回退一级；
  2. **连续 2 课时 LOS 无晋级** → 回查 §3 路由并将小步子步幅减半，记入待调整；
  3. 出现 **N** → 转环境调整＋优先参与目标（先稳住参与再谈学业），不计学业判据；
  4. 自伤 / 攻击 / 长时间逃离 / 呛噎过敏 → **立即危机处置**（降刺激、冷静角、任务降级、移除围观），**必要时启动学校应急预案并按校规上报**（校医 / 班主任 / 家长；记录上报对象与时间），**四条红线：禁体罚、禁惩罚性隔离、禁强制进食、禁当众批评**，事后 ABC 复盘并更新支持卡。
- **干预一致性**：策略固化于"**跨课时行为支持卡**"（触发信号 / 前因调整 / 替代行为 / 强化计划 / 危机处置 / 全员一致要求），随教师版交付，换人或换课时不得漂移。

## 6. 低打扰协议

全流程仅双 Gate（见环节 0）硬性停等，其余环节未获明确否定即续进；每阶段至多一次纠偏提示；确认话术为特异性追问，一次只问当前决策点最关键的 1~2 个问题，不轰炸不阻塞。
