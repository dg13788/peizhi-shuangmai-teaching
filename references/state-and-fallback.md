# 状态管理与容错降级（SKILL.md §5 展开）

> **渐进式披露第二层**。SKILL.md 常驻"落盘文件名 + 熔断阈值 + 降级出口"三行；本文件承载完整口径。

## 1. 落盘

锚定单 `锚定单_{{课题}}.md`（字段：附件识别结果/教材匹配/**课时数N**/Gate-A/Gate-B 状态/基线与假设/框架/成稿与交付状态/待替换项/**行为干预决议记录**/当前环节）；内容提取卡；跨平台无状态一律落盘，恢复会话按锚定单续跑。

## 2. 熔断

同一环节回炉≥2 次→自动补默认＋假设并标注，提示可人工接管；自检连续 2 轮不过同一条目→直接标为待替换项交由人工，不再回炉。

## 3. 降级

- **附件降级**：识别失败→提示粘贴文本等价识别，不静默跳过；唯一学情来源识别失败按 Gate-B 判定。
- **无文件系统**：三视图文本交付，提示本地转 Word（如需 PDF 由使用者在 Word/WPS 内另存，引擎不产出）；异常中断→输出压缩版教案概览（课时安排＋目标矩阵＋LOS 表＋五列表骨架＋行为支持卡要点）并提示接管。
- **退出**：用户终止或红区信息被输入→立即停止并提醒"红区零输入"，不生成任何含红区信息的产物。
- **平台适配**：无状态平台（豆包/Kimi 等）Gate 以"回复确认"推进；有文件系统平台默认交付 Word 成品并过 `references/format-baseline.md` 核验。

## 4. 上下文预算（防长教案生成到一半被截断）

1. **一次一课时**：多课时按课时串行生成，完成即落盘锚定单，不在上下文内同时铺开全部课时；
2. **N>3 的单元课直接拆分为多个锚定单**，先总则后分课时；
3. **压缩优先级**：超限时优先压缩"设计意图"列与叙事性描述，**目标矩阵 / 五列表 / LOS 表 / IEP 追踪表 / 安全替代表 / 支持卡一律不可压缩、不可省略**；
4. **不在上下文内做格式转换或重排**（一律调用「环节 3.5 · 格式交付」的脚本）；
5. 恢复会话先读锚定单，只补齐当前环节所需，不复读全文。

## 5. 幂等与产物一致性（硬保证）

1. **同源**：md 是唯一源稿，JSON 与 docx 只能由 `scripts/md_to_json.py` / `scripts/md_to_docx.py` 派生，**禁手工编辑任何产物**；
2. **字节幂等**：同一 md 生成的 docx 逐字节恒定（已固定压缩时间戳与部件顺序），`python scripts/md_to_docx.py <成品目录> --check` 可验证交付件是否被改过或与源稿失同步；
3. **改动顺序**：先改 md → 重跑派生与生成 → 再跑回归，**顺序颠倒即视为产物漂移**；
4. 重跑**不得追加或重复编号**（禁在已有文件尾部追加表格或章节），重跑即全量重写同名文件。
